# 우리 마을 에너지 시뮬레이터 3D

중학교 기술 수업 「데이터로 찾는 신재생에너지 마을」에서 쓰는 웹 시뮬레이터예요.
우리 모둠 지역의 기상 자료(일조시간·풍속·강수량)를 넣고, 3D 마을에 발전소를 지어 집 50채에 불이 몇 채나 들어오는지 확인해요.

- 바로 열기: https://yu-gyeong2.github.io/energy-village/
- 발전소: 태양광(집 지붕은 작은 패널), 풍력, 수력(내륙 지역만), 조력(바닷가 지역만), 전기 저장소
- 예산 10억 원, 상황 버튼(1년 평균·맑은 낮·흐리고 바람 센 날·밤·바람 없는 밤)
- 결과 복사하기 → 캔바 활동판에 붙여 넣기

## 파일
- `index.html` : 시뮬레이터 전체 (파일 하나)
- `three.min.js` : 3D 그림을 그리는 three.js r128 (MIT 라이선스, `three-LICENSE.txt`)

계산은 지역끼리 비교하기 위한 단순 모형이에요. 계산 방법은 페이지 아래 '선생님용 · 계산 방법과 가정'에 있어요.
